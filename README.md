# SWYNEX Machine Learning Model

## Project Overview

This project focuses on training and evaluating machine learning models using the Titanic dataset as part of the SWYNEX Technologies Internship Task 2.

## Tasks Performed

- Loaded the Titanic dataset using Pandas
- Explored the dataset and identified missing values
- Removed unnecessary columns
- Handled missing numerical values using median imputation
- Handled missing categorical values using most-frequent imputation
- Encoded categorical variables using One-Hot Encoding
- Separated features and target variable
- Split the data into training and testing sets
- Trained Logistic Regression model
- Trained Random Forest Classifier model
- Evaluated both models using different performance metrics
- Compared the performance of both models
- Created model performance visualizations

## Dataset

The Titanic dataset contains passenger information and the target variable `Survived`.

## Models Used

- Logistic Regression
- Random Forest Classifier

## Evaluation Metrics

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- ROC-AUC

## Conclusion

The Logistic Regression and Random Forest models were successfully trained and evaluated on the Titanic dataset. Their performance was compared using multiple evaluation metrics to understand how different machine learning algorithms perform on the same dataset.
